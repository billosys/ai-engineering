## Candidate Rule

Only `knowledge/rust/SKILL.md` and `knowledge/js/SKILL.md` have baseline
entrypoint bundled-reference rows. The candidate rows point to guide files that
are bundled under each package's `guides/` directory, while the source
entrypoints retain useful source-clone wording. These rows are addressed by a
package-stage transform rather than source prose edits.

The transform intentionally does not touch mature guide prose, missing C++
images, missing Rust `09-common-pitfalls.md`, or JavaScript/Deno guide-internal
cross-reference warnings.
