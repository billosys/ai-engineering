roles and relative importance. Size, weight, colour/contrast, position and spacing

CQ7 local answer: a grid is a system of alignment/position/sizing references,
often horizontal and vertical, that helps coordinate repeated choices and relate
new elements to existing ones. Columns supply repeated tracks, margins possible
outer references, tables a content-level row/column case, and maxims5/6 the
consistency problem. Typographic-grids Core/Key Properties provide the definition
and problem directly. This conceptual question can be answered without inventing
a rendered specimen requirement. CSS Grid is optional, data semantics remain
separate, complexity may serve content, and successful alignment proves no
rendered quality. The local answer does not accept the full-corpus CQ7 union.

CQ13 local answer: comparatively smaller spaces within a group and clearer/larger
separation between groups can suggest membership. In the quotation example,
paragraphs inside one extract can share closer gaps, while the extract-to-prose
gap and attribution placement mark its boundary. If within-group gaps rival or
exceed between-group gaps, the intended grouping can become ambiguous. This is
explicit local design reasoning, supported by the quotation's distinct role and
the design SKILL Proximity principle; it is not a measured perception claim or
a numerical spacing rule. Actual content/appearance can qualify the cue.

## Primary support and discriminating checks

- [HTML table semantics](https://html.spec.whatwg.org/multipage/tables.html#the-table-element),
  [caption](https://html.spec.whatwg.org/multipage/tables.html#the-caption-element),
  [th/scope](https://html.spec.whatwg.org/multipage/tables.html#the-th-element):
  distinguish multidimensional data from page layout; caption,headers and
  associations support interpretation. The person/question case is a data table;
  article/navigation placement is visual layout. CSS tracks cannot supply missing
  data semantics. No AT verification is inferred.
- [HTML blockquote](https://html.spec.whatwg.org/multipage/grouping-content.html#the-blockquote-element):
  quoted section, attribution outside. An indented non-quotation stays a styled
  content element; removing outer quotation delimiters must preserve punctuation
  belonging inside the quotation. `cite` does not supply visible attribution.
- [CSS multicol](https://www.w3.org/TR/css-multicol-1/#columns), width/count and
  used-size algorithm: assuming horizontal text,16px root and element font,
  auto count,18rem requested width,2em=2rem gap and no extra constraints/breaks,
  N=max(1,floor((U+2)/(18+2))),W=(U+2)/N−2. U16rem→N1/W16rem;
  U40rem→N2/W19rem. These are analytic used values; actual fragmentation can
  affect count. No finite fixed-height prerequisite or browser witness.
- [CSS Grid order](https://www.w3.org/TR/css-grid-2/#order-accessibility):
  visual placement does not repair meaningful source sequence; guide preserves
  source order and requires actual output review.
- Page width arithmetic:8.5−2×1=6.5in;8.5−2×2=4.5in. A/B change size,leading
  and area too; these dimensions prove no word counts/comfort. Optional2.23in
  ratio case:4.04×6.54in,6.54/4.04≈1.619, geometry only.
- A0.5pt optional decorative divider differs from an essential data boundary.
  `currentColor` avoids prescribing a palette but may match an adjacent surface;
  actual colours,role and output determine visibility. No automatic perception
  or conformance claim follows from the inherited colour or thickness.
