## Focused witnesses

Direct calculations/spec grammar reasoning; these are not runtime/browser
observations. Inputs, method and observed expected result:

| Witness | Method and result |
|---|---|
| RGB precision | `255×0.5=127.5`; channel number `0.5` is not 50%. `rgb(0.5, 0.5, 0.5)` is valid fractional legacy syntax. Modern `rgb(50% 0 0 / 50%)` is valid; mixed-unit comma `rgb(50%, 0, 0)` is invalid. `#0f08` expands `#00ff0088`; alpha `0x88/255=136/255≈0.5333`, not 0.5. |
| Code count | `2^8=256`; `256^3=16,777,216`; alpha adds a storage dimension, not RGB gamut or a universal discrimination threshold. |
| Gradient alpha | Premultiplied-alpha midpoint for transparent white→opaque black is `(0,0,0,0.5)`, not `(0.5,0.5,0.5,0.5)`. Opaque `rgb(255 0 0)`→`rgb(0 0 255)` componentwise in explicit sRGB at t=0.5 gives `(0.5,0,0.5,1)`. E00 resolves the earlier `(0.5,0,0,1)` arithmetic typo; the card now uses the corrected result. No further Operator decision is pending. |
| Matrix | Applying retained 4×5 rows to `(0,0,0,1,1)` yields `(0,1,0,1)`; second output row's alpha coefficient supplies green 1. Identity matrix yields arbitrary RGBA unchanged; a nonzero constant offset makes the mapping affine. |
| Blend | Opaque `Cb=.2,Cs=.4`: multiply `.08`; screen `.52`. Color-burn branches: `Cb=1,Cs=0 → 1`; `Cb=.2,Cs=0 → 0`. Blend function does not replace alpha-compositing equation and does not cover non-separable modes. |
