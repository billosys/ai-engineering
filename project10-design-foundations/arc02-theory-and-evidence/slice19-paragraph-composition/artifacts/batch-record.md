## Focused witnesses and guide consistency

- Nominal size: 12 CSS pt = 16 CSS px. 12pt × 1.35 = 16.2pt = 21.6 CSS px.
  Point size alone does not set cap height or glyph bounds. A conceptual
  OpenType em-space counterexample with upem1000, yMin−250, yMax900 spans
  1150/1000 = 1.15em; this is a logical counterexample, not a measured font.
- CSS line-height: parent20px/child12px with unitless `1.5` yields 30px/18px;
  inherited `150%` computes to30px at the parent and remains30px at the child,
  absent an override. This is the CSS computed/inherited distinction, not a
  Word calibration.
- CSS margins: adjacent positive6px block margins can collapse to6px under
  qualifying conditions, while a non-collapsing context yields12px. A separate
  6px gap is not equivalent to either unconditional rule.
- Old responsive example: at root16px, the clamped font-size candidates are
  16px at viewport320px and20px at1280px; `40vw` widths are128px and512px.
  Matching line counts do not follow. With a synthetic zero advance8px,65ch is
  520px;65 glyphs at4px versus16px advance occupy260px versus1040px before
  shaping. This is a logical illustration, not a real-font count or test.
- Hyphenation and flow: the source and CSS Text require known language and a
  suitable resource for automatic word breaking; language may be inherited
  from an ancestor or local element. Widows/orphans concern fragmented output;
  setting declarations alone demonstrates neither actual breaks nor page
  composition/readability.
- Type guide: adds “Compose readable paragraphs” before “Vary by context and
  review.” The `.prose` example inherits project font and uses illustrative
  `1rem`, `1.35`, `65ch`, `start`, zero scoped paragraph margins and `.75em`
  inter-paragraph margin. The indent rule replaces the gap (`0` margin and
  `1em` text-indent). Language belongs on surrounding HTML. WCAG2.2 AA1.4.12
  override conditions are separated from authored defaults; AAA1.4.8 conditions
  are separate. These statements prescribe future checks; conformance was not
  tested.
