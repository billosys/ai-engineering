## Four difficult cases and wrong interpretations

1. **Default versus universal scope/local pair.** Layout:387–391 calls rules
   exceptionless across the entire system;402–406 removes them for wrappers;
   Center:606–607 distinguishes prose/containers. Compare exact propositions/
   applicability before declaring contradiction. A scoped default can coexist
   with exceptions; blanket60ch on all controls/tables/media is not that default.
   EL itself uses axiom language and selector exceptions; qualifying current
   scope is not proof of historical misquotation.
2. **Measure versus characters/compliance.** Hypothetical zero advance10px
   gives600px for60ch; glyph advances10px and5px yield60 and120 glyphs under
   that toy model. This challenges an identity, not browser wrapping or actual
   font behavior. Apply CV conditions and WC's criterion/level/mechanism; reject
   “60ch always means60 characters” and “this CSS certifies WCAG.”
3. **Intrinsic base versus discrete adaptation.** SKILL:208/272 and layout:
   291–293/974–975 require zero queries. Switcher:670–678 has an intrinsic
   transition threshold without viewport queries. Monoculture:107–111 is a
   separate claim: ch does not justify a chosen threshold. Work a dense
   navigation/actions case where wrapping fits but grouping/task operation
   needs a discrete mode; state rationale/trigger/order/interaction and failure
   checks. Also supply a prose case needing no query. Reasoned cases do not
   establish every dense page needs one; browser behavior remains unrun.
4. **Derivation versus verification.** Layout:395–400 promises correct
   unanticipated outcomes without manual verification of every combination.
   Separate bounded confidence from guarantees. Include long/unbreakable tokens,
   expanded content, changed glyph metrics and a wide2D table/media case.
