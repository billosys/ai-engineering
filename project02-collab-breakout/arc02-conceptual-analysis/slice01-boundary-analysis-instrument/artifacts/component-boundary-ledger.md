## Purpose

This artifact seeds the Arc02 candidate-boundary evaluation. It contains one
row for each of the 26 Arc01 candidate labels from
`../../arc01-framework-inventory/slice03-arc01-synthesis/artifacts/candidate-component-inputs.md`.

Rows are analytical and non-final. This ledger does not decide final
architecture, does not accept component boundaries, and does not replace the
Arc02 planning ledger. Slice02 should complete the evaluation fields using the
method in `artifacts/conceptual-analysis-method.md`.
