## Contract Rules That Apply To Every Component

- Every component gets a component-local `SKILL.md` with a version field and a
  sibling `version-history.md`.
- Every component carries an explicit package/source contract: source path,
  package root, package-local link strategy, installed skill route, README
  route, SKILL route, Makefile impact, generated zip behavior, validation
  command, owner, and versioning contract.
- `engineering-methods` owns the shared source/package/release gates, but that
  ownership does not remove local validation responsibility from the other
  components.
- `agent-coordination` owns CC/CDC/operator terminology, context-packet
  discipline, delegation decisions, and result integration boundaries.
- Memory admission is deferred future research. CCDP remains a separate
  protocol distribution, not a Project02 collaboration-framework component.
