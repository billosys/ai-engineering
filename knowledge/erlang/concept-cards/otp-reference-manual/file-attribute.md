# Quick Definition
The `-file(File, Line)` attribute changes the pre-defined macros `?FILE` and `?LINE` from that point forward. It is primarily used by code generation tools to map generated code back to original source locations.

# Core Definition
The Erlang Reference Manual states: "The same syntax as for module attributes is used for changing the pre-defined macros `?FILE` and `?LINE`." The syntax is `-file(File, Line).` and "this attribute is used by tools, such as Yecc, to inform the compiler that the source program is generated by another tool. It also indicates the correspondence of source files to lines of the original user-written file, from which the source program is produced." (Modules, "Setting File and Line" section).

# Prerequisites
- **erlang-module** -- The file attribute uses module attribute syntax
- **predefined-macros** -- It modifies `?FILE` and `?LINE`

# Key Properties
1. Syntax: `-file(File, Line).` where `File` is a string and `Line` is an integer
2. Changes the values of `?FILE` and `?LINE` from that point forward
3. Affects compiler error and warning messages (they report the overridden file and line)
4. Used by code generators like Yecc and Leex
5. Not typically used in hand-written code

# Construction / Recognition
## To Construct/Create:
1. Write `-file("original_source.yrl", 42).` to indicate that the following code corresponds to line 42 of `original_source.yrl`

## To Identify/Recognize:
1. The `-file(...)` attribute with a string and integer argument
2. Typically found in generated `.erl` files, not in hand-written source

# Context & Application
The `-file` attribute enables accurate error reporting for generated code. When a tool like Yecc (parser generator) or Leex (lexer generator) produces Erlang source code from a grammar or lexer specification, it inserts `-file` attributes so that compilation errors point back to the original specification file and line number rather than to the generated code.

# Examples
**Example 1** (in a Yecc-generated file):
```erlang
-file("parser.yrl", 15).
%% Code generated from line 15 of parser.yrl
```

# Common Errors
- **Error**: Using `-file` in hand-written code without understanding its effects
  **Correction**: This attribute changes error reporting locations; it should only be used when mapping generated code back to original sources

# Common Confusions
- **Confusion**: Thinking `-file` includes or loads a file
  **Clarification**: `-file` does not include any file. It only changes the file name and line number metadata used by the compiler for error reporting. Use `-include` for file inclusion.
