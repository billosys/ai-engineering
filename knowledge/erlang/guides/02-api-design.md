# API Design

Target environment: **Erlang/OTP 27+** (call out where OTP 24/26 behaviour differs). Default toolchain: **rebar3** build · **dialyzer + xref** static analysis · **elvis** style · **erlfmt** formatting · **eunit + common_test + PropEr** tests · **EDoc / -doc attributes** docs.

Grounded in: Programming Rules, Inaka Guidelines, API conventions.
