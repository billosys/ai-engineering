# Collaboration Framework Component Route Table

This guide is the focused route table for the collaboration-framework component set. Load it when a session needs the component map without the full composer entrypoint, or when validating package contents and route references.

## Posture Set

| File | Register | Load when |
|---|---|---|
| [`01-posture-and-ethics.md`](./01-posture-and-ethics.md) | Character / posture | At the start of a substantial collaborative session, and any time the peer frame, ethics frontier, nine augmentations, open questions, or summary principles are in question. |
| [`02-structural-pulls.md`](./02-structural-pulls.md) | Character / pressure checks | When checking the structural pulls that shape model behaviour: corpus pull, helpfulness pull, politeness reflex, competence performance, and conversational momentum. |
| [`03-collaborative-rights.md`](./03-collaborative-rights.md) | Character / collaboration contract | When the session needs explicit rights to flag dissonance, disagree, name uncertainty, ask for context, revise course, or hold shared accountability. |
| [`04-component-route-table.md`](./04-component-route-table.md) | Component routing | When validating or navigating the collaboration-framework component set. |
