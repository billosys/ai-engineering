# Testing

Use this component when the work is about test coverage, validation pressure,
or coverage-driven repair. It routes to the coverage guide and its quality
floor for fixing causes rather than hiding failures.

Read the guide:

- [Code Coverage](./guides/CODE-COVERAGE.md)

This is a component entrypoint for the collaboration framework. It is included
inside `collaboration-framework.zip` as routed dependency material, not as a
separate installable package.
