# Laboratory Recordkeeping Version History

### Version 0.1.0 - 2026-09-22

Initial skill for institutional research collections and practical laboratory
recordkeeping. Adds guides for stewardship, stable identities, progressive
directory creation, unexpected-file handling, journals, run records, storage,
preservation, and reconstruction. Includes reusable templates, worked routing
examples, and an attributed source register drawing on CERN and archival
terminology. Separates reusable method from repository adoption and scientific
inquiry design. Ships as a standalone installable package.
