# Template Retention Disposition

## Disposition

`knowledge/work-verification/templates/LEDGER-DISCIPLINE.md` is retained.

## Rationale

The file still carries useful complete protocol and copyable table material:

- one-file slice, arc, and project protocol context;
- copyable slice ledger table;
- copyable arc ledger table;
- copyable project ledger table;
- full lineage and failure-mode discussion in one support asset.

The new guides are the preferred live routes for selective loading. The
template is no longer the only default work-verification load path; it is a
package-local support/template asset for sessions that need the complete
pre-split protocol in one file.

## Source Treatment

The template was not narrowed. It was updated only to explain its retained
support role and to cross-route to the five focused guides:

- `../guides/01-ledger-discipline.md`
- `../guides/02-evidence-strength.md`
- `../guides/03-row-closure.md`
- `../guides/04-silent-drop-checks.md`
- `../guides/05-independent-verification.md`

## Package Disposition

The retained template remains in `Makefile` `CF_FILES` and is present in the
rebuilt `target/skills/collaboration-framework.zip` at:

- `collaboration-framework/knowledge/work-verification/templates/LEDGER-DISCIPLINE.md`

The package also contains the five new guides. This matches the accepted
architecture, which listed both `work-verification/guides/` and
`work-verification/templates/LEDGER-DISCIPLINE.md`.
