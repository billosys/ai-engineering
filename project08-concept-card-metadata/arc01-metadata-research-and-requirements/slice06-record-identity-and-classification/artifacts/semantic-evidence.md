## Exact scope and evidence boundary

The registry covers exactly 37 root pairs. It now records the current identity
contract (SKILL.md lines 138-144), record-field-groups rows 9-20, templates,
and the available populated records. Templates establish representation and
null placeholders; they do not establish generated populated values.

The shared rule is conditional: stable id and revision preserve record identity;
a reference normally carries id/revision/path, adding record_type or a section
anchor when disambiguation is needed. This is not a mandated type-qualified
composite key and does not establish global ID uniqueness. Each membership
applies that rule to its named construct: claim assertion, CQ question,
extraction-run trace, admission decision, preservation decision,
reconciliation result, relationship edge, locator, support linkage, validation
result, or verification result. Root IDs/revisions are not actor, subject,
endpoint, target, source, or method identities.

## Classification census and comparisons

Frozen inventory query over the music/Erlang legacy population finds all 2,054
records carry category/subcategory/tier keys. Category and tier are strings;
subcategory is a string in 1,974 and null in 80. Observed distinct values:
category 26, subcategory 408 including null, tier 3. The Erlang Behaviour card
is a named null-subcategory example, so null is present data—not missing or
automatic inapplicability.

The v3.2 prompt defines category as primary domain taxonomy, subcategory as
optional finer classification, and tier as foundational/intermediate/advanced.
It defines foundational as no prerequisites within the source. Accent Types
observes tier foundational and prerequisites [meter], while its body says metric
accent depends on meter. Meter is in the same Complete Musician source
directory, creating a bounded tension with that historical definition; this
does not establish a whole graph or prove the card wrong. Erlang
application-behaviour instead observes applications-releases/applications/
intermediate with otp-application prerequisite. Category/subcategory support
legacy discovery; tier supports limited pedagogical filtering, never source
coordinates or a future taxonomy.
