# Expanded Coverage Plan

## Decision Before Extraction

This is a bounded memory-protocol subset, not a full-corpus run. It uses the
pinned `CompCogNeuro/book` commit
`e0c697b4d4d134f29cb5c2bbde41b1b6b409b63d` and tree
`894b3e10baa38e9d9c29a2e52b64f4d0ffb1378a`.

| Included units | Purpose |
| --- | --- |
| Chapter 1, `The Computational Approach` and `Emergent Phenomena` (lines 31-60) | Retain the pilot's methodological framing. |
| Chapter 7, `Memory` through `Priming: Weight and Activation-Based` (lines 5-166) | Build the memory-protocol conceptual spine. |

Excluded: Chapters 2-6 and 8-10, Chapter 7's implementation appendix
(168-184), full bibliography resolution, and all 131 figures beyond direct
inspection of claim-dependent pilot figures. Full-book extraction would create
unreviewed breadth and dependency work that this slice cannot validate.

The expected set is the four Slice02 pilot candidates plus six new Chapter 7
candidates, each with a claim-specific support section and unassessed lifecycle
fields. Re-enter full-book coverage only when a later slice defines chapter
coverage, figure/citation sampling, reviewer capacity, and validation sampling
before generation.

Stop if source identity differs, a selected claim lacks an inspectable span,
or a required figure/citation/cross-reference cannot be inspected or caveated.
